Flight Disruption Recovery Agent

CSE 510 Agentic Engineering, team project. I owned the agent brain.

  • Python
  • Finite-state machine
  • LLM intent parsing
  • Simulated tools
  • Evaluation harness

The problem

An agent that replans disrupted flights can't improvise actions with real consequences. It has to stay inside the rules and stop for a human at the right points.

What I did

I built the agent brain as a Python finite-state machine with bounded retries and replanning, explicit approval gates, and rule-based fallbacks. The LLM only parses intent and words messages. Deterministic code controls every transition and validates constraints through local simulated tools, and recommendations never book or pay.

What changed

  • 30/30simulated scenarios passed by the integrated team system, with zero violations in the team evaluation harness

ClearVox: speech recognition for impaired speech

Student Researcher, University at Buffalo IAD, Aug 2026 – Present. Supervised by Prof. Siwei Lyu.

  • PyTorch
  • Whisper-medium
  • Flan-T5-small
  • XTTS-v2
  • ECAPA-TDNN
  • UTMOS
  • Streamlit

The problem

Speech recognition trained on typical speech struggles with impaired speech such as dysarthria. ClearVox recognizes it, corrects the transcript, and synthesizes it again with voice cloning.

What I did

I built the recognition, correction, and voice-cloning pipelines. I fine-tuned Whisper-medium on TORGO (8 speakers, 3,246 utterances) and Flan-T5-small on 1,446 correction pairs, and added XTTS-v2 synthesis with a verify-and-retry loop evaluated with ECAPA-TDNN and UTMOS. I deployed a three-page Streamlit research demo on an RTX 4090, using half precision and CPU placement to reduce GPU memory. The project began under the SUNY Research Foundation and continues at UB.

Results, and how each was measured

ComponentResultEvaluation setting
Whisper-medium22.6% macro WERLeave-one-speaker-out on TORGO (test speaker never seen in training)
Whisper-medium15.8% WER / 10.6% CERSeparate evaluation on 622 held-out utterances
Severe-speaker adaptationWER 50.5% → 38.0%One severe speaker, adapted with 71 clips
Flan-T5-small correctionWER 41.5% → 37.8%Validation WER after correction
XTTS-v2 synthesis7/8 verifiedTest utterances, verify-and-retry
Stuttering checkTuned 24.2% vs stock 20.0% WER483 stuttering clips I built from CHAT transcripts; difference 95% CI +3.4 to +5.4 points (interview resampling)

The last row is a negative result, and I report it on purpose: the tuned model did worse than stock on stuttered speech, which revealed a distribution shift that an overall average would hide.
